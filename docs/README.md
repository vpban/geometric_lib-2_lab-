# Geometric lib - библиотека геометрических вычислений

## Общее описание решения

Библиотека "geometric lib" представляет из себя набор функций для вычисления периметра и площади геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Описание функций с примерами

### Круг (`circle.py`)

- `area(r)` - вычисляет площадь круга.
    - **принимает:** радиус `r (int)`
    - **возвращает:** площадь круга (`S (int)` = πR²)
    - **пример:** `area(3)` → `28.274333882308138`
- `perimeter(r)` - вычисляет длину окружности.
    - **принимает:** радиус `r (int)`
    - **возвращает:** длину окружности (`P (int)` = 2πR)
    - **пример:** `perimeter(3)` → `18.84955592153876`

### Прямоугольник (`rectangle.py`)

- `area(a, b)` - вычисляет площадь прямоугольника.
    - **принимает:** стороны `a (int)` и `b (int)`
    - **возвращает:** площадь прямоугольника (`S (int)` = ab)
    - **пример:** `area(4, 5)` → `20`
- `perimeter(a, b)` - вычисляет периметр прямоугольника.
    - **принимает:** стороны `a (int)` и `b (int)`
    - **возвращает:** периметр прямоугольника (`P (int)` = 2a + 2b)
    - **пример:** `perimeter(4, 5)` → `18`

### Квадрат (`square.py`)

- `area(a)` - вычисляет площадь квадрата.
    - **принимает:** сторону `a (int)`
    - **возвращает:** площадь квадрата (`S (int)` = a²)
    - **пример:** `area(5)` → `25`
- `perimeter(a)` - вычисляет периметр квадрата.
    - **принимает:** сторону `a (int)`
    - **возвращает:** периметр квадрата (`P (int)` = 4a)
    - **пример:** `perimeter(5)` → `20`

### Треугольник (`triangle.py`)

- `area(a, b)` - вычисляет площадь треугольника.
    - **принимает:** высоту `a (int)` и основание `b (int)`
    - **возвращает:** площадь треугольника (`S (int)` = ab/2)
    - **пример:** `area(4, 5)` → `10.0`
- `perimeter(a, b, c)` - вычисляет периметр треугольника.
    - **принимает:** стороны `a (int)`, `b (int)` и `c (int)`
    - **возвращает:** периметр треугольника (`P (int)` = a + b + c)
    - **пример:** `perimeter(3, 4, 5)` → `12`
